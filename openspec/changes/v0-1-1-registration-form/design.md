# Design: v0.1.1 手机号登录

## 页面结构

```
┌──────────────────────┐
│  状态栏（模拟）       │  ← 手机浏览器顶部模拟条
├──────────────────────┤
│                      │
│     🔢 数独游戏      │  ← 标题
│   每日一局，越玩越聪明 │  ← 副标题
│                      │
│   ┌────────────────┐ │
│   │ 📱 请输入手机号  │ │  ← 手机号输入框（11 位）
│   └────────────────┘ │
│                      │
│   ┌──────────┐ ┌───┐ │
│   │ 验证码    │ │获取│ │  ← 验证码输入框 + 获取按钮（60s 冷却）
│   └──────────┘ │验证码│ │
│                └───┘ │
│                      │
│   ┌────────────────┐ │
│   │     登  录     │ │  ← 登录按钮
│   └────────────────┘ │
│                      │
│   首次登录即自动注册  │  ← 说明文字
│                      │
└──────────────────────┘
```

## 用户流程

```
打开网址
  │
  ├── 已有有效登录态 ──→ 首页
  │
  └── 无登录态 ──→ 登录页
                    │
                    ├── 输入手机号
                    │     ├── 格式校验失败 → 输入框下方红色提示
                    │     └── 格式通过 → 可点击"获取验证码"
                    │
                    ├── 点击"获取验证码"
                    │     ├── 按钮进入 60 秒冷却倒计时
                    │     └── Toast 提示 "验证码已发送"（模拟）
                    │
                    ├── 输入验证码（6 位分格输入）
                    │     └── 支持粘贴 6 位数字
                    │
                    ├── 点击"登录"
                    │     ├── 验证码正确（321456）→ 保存登录态 → 跳转首页
                    │     └── 验证码错误 → 页面内错误提示，清除验证码输入
                    │
                    └── 退出登录（在首页触发）
                          └── 清除登录态 → 回到登录页
```

## 状态设计

### 登录表单状态

| 状态 | 说明 |
|------|------|
| `idle` | 初始状态，手机号和验证码均为空 |
| `phone-input` | 正在输入手机号 |
| `phone-valid` | 手机号格式校验通过，获取验证码按钮可点击 |
| `phone-invalid` | 手机号格式不正确，显示错误提示 |
| `code-sending` | 模拟发送验证码中（可省略，直接进入冷却） |
| `code-sent` | 验证码已发送，按钮进入冷却倒计时 |
| `code-input` | 正在输入验证码 |
| `code-complete` | 6 位验证码输入完毕，登录按钮可点击 |
| `submitting` | 正在验证登录 |
| `login-error` | 登录失败，显示错误信息 |
| `login-success` | 登录成功，即将跳转 |

### 登录态

| 字段 | 说明 |
|------|------|
| 手机号 | 已登录玩家的手机号 |
| 登录时间 | 本次登录的时间戳 |
| 有效期 | 登录态的有效截止时间（待确认） |

## 校验规则

### 手机号

- 必须为 11 位数字
- 必须以 1 开头
- 第二位不能是 0、1、2（即排除 10x、11x、12x 开头）— 待确认是否严格执行
- 输入过程中实时校验，但仅在失焦或点击登录时显示错误

### 验证码

- 必须为 6 位数字
- 固定正确值：`321456`
- 大小写不敏感（仅数字输入，无此问题）
- 错误时清除已输入的验证码，提示用户重新输入

## 交互细节

### 获取验证码按钮

- 默认文案："获取验证码"
- 冷却中文案："{N} 秒后重发"
- 冷却时长：60 秒
- 冷却期间按钮置灰不可点击
- 冷却结束后恢复默认文案和可点击状态
- 手机号变更时重置冷却（待确认）

### 验证码输入

- 6 个独立的输入格，每格 1 位数字
- 输入一位后自动聚焦下一格
- 按退格键删除当前格并回到上一格
- 支持从剪贴板粘贴 6 位数字一次性填充
- 输入完成后自动聚焦登录按钮（或自动提交 — 待确认）

### 错误反馈

- 手机号格式错误：输入框变红 + 下方红色文字提示
- 验证码错误：验证码输入格抖动或变红 + Toast/行内提示 "验证码错误，请重新输入"
- 所有错误反馈在当前页完成，不弹出对话框、不跳转独立错误页

## 待确认设计决策

- 登录态有效期（7 天？30 天？永久？）
- 手机号格式校验的严格程度（是否校验真实号段）
- 验证码输入完成后是自动提交还是需要手动点登录按钮
- 获取验证码按钮冷却期间，修改手机号是否重置冷却
- 是否需要"记住此设备"选项
